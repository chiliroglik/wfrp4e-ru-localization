# Инструкции проекта локализации WFRP4e

- Цель: Foundry V14, WFRP4e 10.0.3. Этот репозиторий содержит только русификатор, не старый генератор.
- Сохранять module ID wfrp4e-ru-overlay, исходные UUID, ID документов, правила и статистику.
- Не заменять одобренные тексты и иллюстрации без запроса владельца.
- Не менять системные скрипты ради перевода их подписей. Новая механика допускается только по явному запросу владельца.
- Не добавлять миры, базы, официальные модули, PDF/OCR, резервные копии, токены и ключи.
- module/ — готовая устанавливаемая структура; translations/ — редактируемые исходные блоки. Упаковка не выполняет перевод и не переписывает одобренный контент.
- Любое изменение словарей требует согласованного обновления контрольных сумм и проверки привязок.
- Перед релизом: python tools/package_release.py; python tools/validate_helf_inputs.py; node --test tests/helf-translation.test.mjs tests/runtime/native-specialisation.test.mjs tests/runtime/paranoth-wheel.test.mjs.
- Не объявлять runtime-проверку пройденной без фактического запуска Foundry. Рабочий мир владельца не менять; GM-слот не занимать.
