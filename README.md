# WFRP4e — Русская локализация

Отдельный модуль русификации **WFRP4e** для Foundry VTT 14. Проверено: Foundry 14.368, система WFRP4e 10.0.3, официальные дополнения 7.2.0. Текущий кандидат: **0.3.0-dev.39 (prerelease)**.

Переводы: Core Rulebook, Archives of the Empire I–III, Winds of Magic и High Elf Bundle. Совместимость русских навыков/талантов, выбор школы через Колесо Паранота. Это самостоятельный проект локализации; прежний генератор персонажей и его история сюда не входят. Технический ID `wfrp4e-ru-overlay` сохранён для совместимости.

## Установка

Нужны Babele, ru-wfrp4e и оригинальные дополнения, материалы которых вы используете. Система, официальные модули и их лицензии в поставку не входят. Символы Ветров берутся из установленного Winds of Magic, изображения не распространяются вместе с русификатором.

Setup → Add-on Modules → Install Module → Manifest URL:

`https://github.com/chiliroglik/wfrp4e-ru-localization/releases/download/v0.3.0-dev.39/module.json`

Адрес заработает после публикации prerelease с приложенными `module.json` и ZIP. Включите модуль в мире, выберите русский язык, установите overlay последним в приоритетах переводов и обновите страницу Ctrl+F5. Ранее импортированные мировые документы могут сохранять прежний текст.

## Разработка и сборка

- `module/` — полный устанавливаемый модуль: JS/CSS, словари, привязки ID и манифест.
- `translations/` — редактируемые исходные блоки переводов; отделены от собранных словарей `module/translations/`.
- `tests/` — переносимые проверки без платных пакетов и локальных миров.
- `tools/package_release.py` — проверка и упаковка текущего `module/`.
- `docs/` — происхождение сборки, релизные заметки и известные ограничения.

Python 3.14, Node 24:

```sh
python tools/package_release.py
python tools/validate_helf_inputs.py
node --test tests/helf-translation.test.mjs tests/runtime/native-specialisation.test.mjs tests/runtime/paranoth-wheel.test.mjs
```

Готовые файлы появляются в `dist/`: ZIP, внешний module.json, SHA256SUMS.txt, описание релиза. Архив содержит только `wfrp4e-ru-overlay/`. Материалы PDF/OCR, локальные базы и резервные копии не требуются для этой упаковки. Редактирование исходных блоков не заменяет обновление собранного словаря: при изменении одобренного перевода нужно согласованно обновить runtime-словарь, его контрольную сумму и тесты. Упаковщик сам не переводит и не изменяет тексты.

## Статус

Колесо проверено под Player и принято владельцем: выбор восьми Ветров, отмена, покупка за 100 XP, сохранение школы и существующих навыков. Проверено отображение 1576×908 и 1280×720. Автоматические проверки не заменяют полную игровую приёмку.

Известны ошибки штатного генератора: дубли Смекалка/Savvy, отсутствующая импортированная таблица star-sign и ошибка её обработки, стартовые предметы-заглушки мага, часть английских динамических строк. Остаются 35 несовпадений отображения WOM Actors и две исходные ссылки High Elf. [Подробнее](docs/RELEASE_NOTES.md).

Перед использованием в игровом мире проверьте модуль на отдельной копии и сохраните свою резервную копию.
