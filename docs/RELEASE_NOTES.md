# WFRP4e RU Overlay — v0.3.0-dev.39

Предварительный релиз для Foundry VTT 14 (проверено 14.368) и WFRP4e 10.0.3. Это отдельный русификатор поверх установленных официальных модулей, Babele и ru-wfrp4e.

## Состав
Переводы Core Rulebook, Archives of the Empire I–III, Winds of Magic и High Elf Bundle. Официальные модули, система, миры, базы, лицензии, исходные PDF/OCR и резервные копии в архив не входят. Для символов Колеса Паранота используется установленный Winds of Magic; его изображения не распространяются вместе с русификатором.

## Новое относительно dev.37
- Колесо Паранота при покупке «Школы магии»: восемь Ветров, подсветка выбора, подтверждение и отмена без списания XP.
- Сохранение конкретной школы/sourceId; отсутствующие Концентрация выбранного Ветра, Язык (магический), Знание (магия) добавляются с 0 повышений, существующие сохраняются.
- Поиск навыков и талантов Core без зависимости от регистра, выбор специализаций, подтверждение покупки серых талантов.
- Русские названия дополнений, папок и библиотек сцен восстанавливаются после переинициализации.

## Установка
1. Установить нужные официальные дополнения, Babele и ru-wfrp4e. Русификатор не заменяет их.
2. На экране Setup → Add-on Modules → Install Module вставить URL module.json этого релиза.
3. В тестовом мире включить зависимости и WFRP4e - Russian Translation Overlay, выбрать русский язык. Overlay должен применяться последним в приоритетах переводов.
4. Обновить страницу Ctrl+F5. Проверить библиотеки и покупку «Школы магии».
5. Для обновления существующего мира сначала сохранить собственную резервную копию. Переводы библиотек не означают автоматическое обновление ранее импортированных мировых документов.

## Проверено
353 Node-теста, 42 Python-теста перевода ранее проверенной базы; дополнительные проверки синтаксиса, JSON, ZIP CRC и ресурсов. 25 файлов перевода побайтово сохранены. Реально проверены Player: покупка через серую кнопку, восемь секторов, отмена, покупка Огня за 100 XP, сохранение школы и отсутствие дублей существующих навыков. Окна 1576×908 и 1280×720. Владелец подтвердил работу колеса.

## Известные ограничения — prerelease
- Штатный генератор может создать две копии таланта при совпадении русского и английского названия (Смекалка/Savvy).
- В тестовом мире отсутствует импортированная таблица star-sign: бросок Archives II завершается TypeError; требуется исправление обработки отсутствующей таблицы.
- Стартовый пергамент, гримуар и посох ученика мага могут стать предметами-заглушками вместо реальных записей.
- В генераторе остаются английские динамические строки; в WOM Actors выявлены 35 несовпадений отображения.
- Две исходные ссылки High Elf пока не разрешены; полная проверка боя, аур и всех карьер не завершена.

Эти ограничения не исправлялись добавлением колеса. Подробные результаты: PARANOTH_DEV39.md и CHARGEN_PLAYER_DEV38.md. Релиз предназначен для тестовой установки.
